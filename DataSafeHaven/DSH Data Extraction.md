Regardless of the fact that data in the DSH is already anonymised, users still have a responsibility to ensure that any data extracted from the DSH cannot lead to the identification of an individual.

Statistical Disclosure Control (SDC) is the basic idea that, using some statistical information, it could be possible to infer confidential information, and even identify someone, from a set of results that have been released. This applies to any figures or tables generated using the data.

Please provide the following details for the data you wish to extract;

1.	Your name, organisation and reason for request.
2.	Which tables in the DSH are you using for your analysis.
3.	For any tables you wish to export, give the column names.
4.	For any graphs you wish to export, give the axes names.

For full details on SDC, see https://ukdataservice.ac.uk/app/uploads/thf_datareport_aw_web.pdf
